# Rishabh Yadav — Portfolio

Personal portfolio website for **Rishabh Yadav** — Freelancer · Website Developer · AI Engineer.

Built with React, Vite and Tailwind CSS on the [Base44](https://base44.com) platform.

## Stack
- React + Vite
- Tailwind CSS
- DM Serif Display + Manrope typography
- Framer Motion

## Pages
Home · About · Services · Projects · Testimonials · Blog · Contact

## Design
A warm editorial palette — ivory, espresso and terracotta — with organic curves and a premium editorial layout.
